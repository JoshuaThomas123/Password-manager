Password Manager
A secure desktop password manager built with C# and MongoDB, designed to demonstrate a full project lifecycle with CI/CD principles and DevOps practices.

What It Does
Securely store and manage encrypted user credentials
Add, view, update and delete saved passwords through a clean desktop interface
Containerised environment ensures consistent behaviour across machines


	
Language	C#
UI Framework	WinForms
Database	MongoDB
Containerisation	Docker
Version Control	Git

Getting Started
Prerequisites
.NET SDK installed
Docker installed
MongoDB running (locally or via Docker)
Run the Application
1.Clone the repository
2.Open the project in your IDE
3.Run Program.cs to launch the application
Run with Docker
bash
docker-compose up

Project Highlights
Encrypted credential storage: user passwords are stored securely in MongoDB
Full project lifecycle: planned, built, tested and documented from start to finish
CI/CD principles: iterative development supported by Git workflows, testing and clear documentation
Dockerised deployment: containerised with Docker for portability and environment consistency
DevOps focus: emphasis on deployment reliability and professional development practices
